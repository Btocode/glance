# Glance Plan 0 — Spike Findings

Machine: Ubuntu GNOME on X11 (`XDG_SESSION_TYPE=x11`), two monitors: `eDP` 1920x1080+0+0 (primary), `HDMI-1-0` 1920x1080+1920+0. System Python 3.10.12, `/usr/bin/python3`.

Every check adds one row to its task's table. Result is one of GO / NO-GO / GO-WITH-CHANGE. Test text everywhere is the synthetic sentence `Teh quick brown fox jump over the lazy dog, i think its fine.` (61 characters).

## Task 2 — Chromium / Electron accessibility

Versions: Google Chrome 158.0.8127.88, Brave Nightly 159.1.102.30, Slack 4.53.292, Discord app 1.0.170, Firefox snap 161.0 (S2.4 and S2.7 only; the rest of Firefox is Task 3). AT-SPI application names: `Google Chrome`, `Brave Browser Nightly`, `slack`, `Discord`, `Firefox`; toolkit name `Chromium` (version `1.0`) for the first four, `Gecko` for Firefox.

Method, and where it departs from the plan:

- Browsers ran as separate instances on fresh temporary profiles (`--user-data-dir=<tmp> --no-first-run --no-default-browser-check`, Firefox `--no-remote --profile <tmp>`). The user's own Chrome (no flag) was left running and untouched, because quitting it would have dropped its tabs (session restore is off). Every tested instance started from zero processes on its profile, and the flag was confirmed in `/proc/<pid>/cmdline` of the instance under test. Slack and Discord were quit with SIGTERM (no process left) and relaunched as `/usr/bin/slack --force-renderer-accessibility` and `/usr/bin/discord --force-renderer-accessibility --url --`, then quit again and relaunched without the flag.
- Typing is XTEST-synthesised, 61 keys, at 70 ms/key and again at 30 ms/key. Events were captured by an ungated recorder that calls `probe.read_field` for every probe event from the app's pid and logs whether the source had FOCUSED, so the probe's focus gate is evaluated rather than assumed. `ms` below is `read_field` alone; "with gate" adds the application lookup and the `_is_focused` round trip, as the probe CLI does.
- `gnome-screenshot` is not installed. The visible caret was located by capturing the root window with Gdk (10 frames, 130 ms apart) around the field and taking the pixels that blink; every visible caret found was 1 px wide.
- Slack text went into an empty draft in the user's own DM. Discord: no private test server could be identified, and typing in a shared channel broadcasts a typing indicator, so nothing was typed in a Discord channel composer. The Discord composer was focused and read while empty, and the typed checks ran in Discord's search box (the same Slate editor, no audience). All drafts were cleared and verified empty.
- `spike/probe.py` `_doc_url` now falls back to the `URI` attribute (S2.4). Nested editors needed a helper that follows U+FFFC at the caret offset through `Atspi.Hypertext` to the block that holds the caret ("leaf" below).
